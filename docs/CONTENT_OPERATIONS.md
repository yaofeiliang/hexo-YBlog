# 内容运营与自动简报

## 定位

本站以原创技术实践为主；自动资讯仅作为「每日技术简报」，帮助读者发现 Node.js、云原生与 AI 的官方动态，不替代原创内容。

## 自动简报原则

1. 仅拉取 `automation/config/sources.json` 中的官方 RSS。
2. 不抓取正文、图片，不转载全文；每条保留原文链接和来源。
3. 自动任务只创建 PR；合并 PR 才会触发站点发布。
4. 同一 URL 只会入选一次，状态保存在 `automation/state/seen-urls.json`。
5. 无合格条目、来源失败或质量校验失败时不发布空洞内容。

## 人工审核清单

- 标题、来源链接和发布日期是否正确。
- 是否真的是读者相关的技术动态。
- 是否包含敏感、错误或不适合个人品牌的内容。
- 是否应补一段你的个人判断，而不仅是链接集合。

## AI 导读的后续要求

启用 AI 前必须：使用独立 Secret；只传 RSS 摘要；限制每条导读长度；强制来源声明；对版本号、CVE、金额和性能数字进行人工审核。AI 不得自动直接发布。
