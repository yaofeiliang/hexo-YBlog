# Y Blog 专业化路线图

## 产品目标

建立一个以原创技术实践为核心、以可信技术简报为补充的中文个人品牌站。自动化负责重复劳动，发布判断与观点仍由作者负责。

## 已具备

- Hexo 8、静态部署、RSS、结构化数据与 WebP 图片。
- 无 jQuery/Bootstrap 的轻量主题、懒加载评论与移动端适配。
- Pagefind 全文搜索。
- RSS 白名单、去重与每日简报 PR 自动化。

## 下一阶段

1. 合并上线分支，并在 GitHub Pages 中启用 `gh-pages`。
2. 在 GitHub `Settings → Actions → General` 允许工作流读写权限和创建 PR。
3. 观察两周的自动简报 PR，持续调整来源白名单和主题关键词。
4. 为原创文章加入系列、阅读时长、相关文章和独立分享图。
5. 接入 Search Console / 百度资源平台、可用性监控与月度内容复盘。

## 自动化边界

- 自动化可以收集、筛选、去重和生成带来源的链接简报。
- 自动化不会抓取全文、绕过付费墙或复制来源图片。
- 自动化不会直接发布到线上；每份简报必须以 PR 形式审核。
- 启用 AI 导读前，必须配置独立 Secret、事实校验和人工审核规则。
